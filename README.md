# varamon

Receive-only monitor for VARA HF signals. It finds each transmission in a recording or a live audio input, works out its speed level and decodes the frame.

Covers the 2300 Hz mode, levels 1 to 16. It does not transmit.

## Use

Python 3.11 or newer and numpy.

```
pip install numpy
python -m varamon                   # web page: open a recording or pick an audio input
python -m varamon recording.wav     # text output
python -m varamon --help
```

Recordings are 16-bit WAV of the receiver's audio in USB. The first run prepares its tables, which takes about a minute. On Windows use `py` instead of `python`.

`python -m varamon --selftest` checks the installation with generated signals.

## Status

Levels 1 and 2 are verified against a real off-air recording. Levels 3 to 16 are verified only against signals generated by this program. Control bursts are not decoded and frame contents are shown as bytes.
